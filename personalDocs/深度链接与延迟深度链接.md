# 深度链接与延迟深度链接

## 概述

深度链接解决“打开 App 后进入哪里”的问题；延迟深度链接解决“用户安装 App 之后还能不能回到安装前点击的目标页面”的问题。它们常用于广告投放、活动落地页、邀请奖励、充值页、任务页等场景。

## 核心概念

| 概念 | 解决的问题 | 典型路径 |
| --- | --- | --- |
| 深度链接 | App 已安装时，点击链接后直达 App 内指定页面 | 点击链接 → 唤起 App → 进入活动页 / 商品页 |
| 延迟深度链接 | App 未安装时，安装后首次打开仍能识别原始目标 | 点击链接 → 下载 App → 首次打开 → 恢复目标页面 |

示例：

```text
https://example.com/activity?id=888
```

App 已安装时，应进入活动 `888`，而不是只打开首页。App 未安装时，则需要第三方平台或服务端保存“用户曾点击过这个目标”。

## 巨量和 Adjust 的作用

国内场景里的“巨量”通常指巨量引擎 / 巨量广告链路，海外场景里的 Adjust 是常见移动归因平台。它们的共同作用不是替 App 做页面跳转，而是记录并回传安装前的点击信息。

它们通常负责：

- 记录用户点击了哪个广告或链接
- 保存点击时携带的深度链接参数
- 归因用户后续是否安装并打开 App
- 在 App 首次启动时，通过 SDK 或回调把链接信息传回 App

关键点：App 未安装时无法自己保存点击上下文，所以延迟深度链接必须依赖平台、服务端或系统级机制中转。

## 两种流程

### App 已安装

```text
用户点击链接
→ 系统识别可唤起 App
→ App 收到 deep link 参数
→ 路由到指定页面
```

### App 未安装

```text
用户点击广告 / 链接
→ 跳转下载页或应用商店
→ 用户安装并首次打开 App
→ 巨量 / Adjust 返回安装前的链接参数
→ App 判断当前是否允许跳转
→ 允许则进入目标页面
```

## 为什么不能拿到回调就跳

延迟深度链接的难点不在“能不能拿到参数”，而在“什么时候还能跳”。

典型风险：

```text
0 秒：App 启动
1 秒：首页展示
2 秒：用户点击“我的”
3 秒：归因平台回调 deep link
```

如果第 3 秒强制跳到活动页，用户会觉得自己刚才的操作被打断。因此产品要求里的“首页需不需要跳 / 拿到回调时判断能不能跳”，本质是在保护用户当前操作上下文。

## 推荐跳转条件

只有同时满足以下条件，才执行自动跳转：

- 用户当前仍在首页
- 首页推荐弹窗、新手引导、运营推荐等尚未展示
- 用户没有点击过其他功能
- 用户没有离开过首页，即使后来又返回首页也不应再自动跳
- deep link 目标仍然有效，活动未下线，参数未过期

可以把它抽象成一个闸门：

```text
收到 deep link 回调
→ 校验目标有效性
→ 判断用户是否仍处于“未主动操作”的启动阶段
→ 满足条件才自动跳转
→ 不满足则丢弃、缓存为入口提示，或交给首页运营位展示
```

## 可补充的实现点

### 1. 记录启动期用户行为

App 可以维护几个布尔状态：

```text
isOnHome = true
hasUserInteracted = false
hasLeftHome = false
hasHomeRecommendationShown = false
```

任何点击、Tab 切换、页面跳转、弹窗展示，都可能改变这些状态。深度链接回调到达时只读这些状态做判断。

### 2. 区分冷启动和热启动

- 冷启动：更适合自动跳转，但仍要等首页初始化和权限弹窗处理完成。
- 热启动：用户可能正在 App 内操作，自动跳转要更保守。
- 首次安装启动：延迟深度链接主要发生在这里，但也要处理隐私授权、登录态初始化等前置条件。

### 3. 登录态和页面权限

目标页可能要求登录、实名、地区、版本或权限。不要只根据 URL 跳转，应先校验：

- 用户是否已登录
- 目标页面是否存在
- 活动是否还有效
- 当前 App 版本是否支持该目标页
- 是否需要先完成注册、登录或权限授权

### 4. 未跳转时如何处理

不是所有被拦截的 deep link 都要直接丢弃。可以按业务价值选择：

- 高价值活动：在首页展示轻提示或运营入口
- 普通页面：静默丢弃
- 邀请奖励：缓存参数，等用户登录后再绑定邀请关系

## 结论

延迟深度链接不是“回调来了就跳”，而是“回调来了以后判断用户是否仍处在可被系统引导的阶段”。实现时要同时处理归因平台回调、App 路由、首页状态、用户操作、登录权限和降级策略。
