# SEO 项目知识库

专门收录与 SEO 相关项目实践中的框架与优化知识，按主题分类存放。

## 目录结构

| 目录 | 用途 |
|------|------|
| [`nuxt/`](./nuxt/) | Nuxt 框架相关（SSR/SSG、路由、渲染模式、模块等） |
| [`nextjs/`](./nextjs/) | Next.js 框架相关（App Router、SSR/SSG、Metadata、中间件等） |
| [`seo/`](./seo/) | 通用 SEO 知识（索引、元信息、sitemap、结构化数据、性能与可抓取性等） |

## 使用约定

- 单篇知识点落盘为 Markdown，文件名用中文主题即可
- 与具体框架强绑定的内容放 `nuxt/` 或 `nextjs/`；跨框架通用原则放 `seo/`
- 新增文档时，可在对应子目录 `README.md` 的索引中补一行链接
