# 预签名上传（Presigned Upload）

## 1. 是什么

后端使用云存储的 AK/SK 生成一个临时上传 URL，前端拿这个 URL 直接上传文件到 OBS/S3。

```
前端
  │ ① 请求上传地址
  ▼
后端
  │ ② 生成 Presigned URL
  ▼
前端
  │ ③ PUT 文件
  ▼
OBS / S3
```

## 2. 优点

- 文件不经过业务服务器
- 减少服务器带宽和压力
- AK/SK 不暴露给前端
- URL 有有效期和权限限制

## OBS CORS 与 CDN CORS

```
Browser → OBS
```

→ 查 OBS CORS

```
Browser → CDN → OBS
```

→ 优先查 CDN CORS

```
上传：Browser → OBS

下载/展示：Browser → CDN → OBS
```

预签名上传一般不建议经过 CDN。

```
                 上传

Browser
   │
   │ Presigned PUT
   ▼
OBS


                 下载 / 图片展示

Browser
   │
   │ GET
   ▼
CDN
   │
   │ Cache Miss 才回源
   ▼
OBS
```
